# eMarketSelect landing page

Responsive company landing page with GSAP / ScrollTrigger animations and Lenis smooth scrolling.

## Run locally

From the repository directory, run:

```sh
python -m http.server 8000
```

Open http://localhost:8000. No build step is required.

## Files

- `index.html`: page content and navigation
- `styles.css`: layout, responsive styles, and color treatments
- `fonts.css`: local Satoshi font definitions
- `app.js`: scroll sequences, text reveals, menu, and adaptive logo contrast
- `assets/`: company images, logos, fonts, and bundled animation libraries

Deploy the repository root with any static web host. Company and third-party assets retain their respective ownership and licenses.
